# 06 · 海洋（M5）

## 解决的问题
1. **海浪要随机、自然，而不是噪声形变**：用海洋学的线性波浪理论 —— 海面是大量正弦波的叠加，每个波的振幅来自实测拟合的频谱，传播速度由色散关系决定。浪的形状、速度、波长分布都「对」，而不只是看起来在动。
2. **可调节波高与密度**：风速、风区长度、方向集中度、涌浪决定频谱（物理参数）；波高倍数、尖锐度是在物理结果之上的艺术控制。
3. **翻腾的浪有泡沫**：浪头被挤压到「折叠」时起泡，泡沫随时间消散、随水面一起移动；岸边浅水另有泡沫带。
4. **参考实现与优化实现**：Gerstner（几十个波，简单、CPU 可精确查询高度）与 FFT（三级联 × 256²，几十万个波）共用同一份频谱，编辑器里一键切换对比。
5. **水本身的光学**：菲涅尔反射天空、太阳高光、浪尖透光、按 RGB 分别吸收的折射（浅水透出沙床、深水发蓝绿）。

## 关键设计

### 频谱：海面的「统计配方」
**色散关系**（有限水深）：$\omega^2 = g\,k\,\tanh(kh)$ —— 深水时 $\omega=\sqrt{gk}$，长波跑得快；浅水时 $\omega\approx k\sqrt{gh}$，所有波一样快。

**JONSWAP**（北海观测拟合的风浪能量谱）：

$$S(\omega)=\frac{\alpha g^2}{\omega^5}\exp\!\left[-\frac54\left(\frac{\omega_p}{\omega}\right)^4\right]\gamma^{\exp\left[-\frac{(\omega-\omega_p)^2}{2\sigma^2\omega_p^2}\right]},\quad
\alpha=0.076\left(\frac{U^2}{Fg}\right)^{0.22},\ \omega_p=22\left(\frac{g^2}{UF}\right)^{1/3}$$

$U$ 风速、$F$ 风区长度、$\gamma$ 峰值增强。再乘 TMA 浅水修正 $\phi(\omega_h)$ 与波高倍数²。
**方向分布** $D(\theta)\propto\cos^{2s}(\theta/2)$，数值归一化到积分为 1。
**换算到二维波数谱**：$S(\vec k)=S(\omega)\,D(\theta)\,\frac{d\omega}{dk}\,\frac1k$（因为 $d\vec k = k\,dk\,d\theta$）。
**有效波高** $H_s=4\sqrt{m_0}$，$m_0=\int S(\omega)d\omega$。面板上实时显示的就是它（默认 9 m/s、150 km 风区在 1~2 m 之间，单元测试检查这个量级）。

### FFT：几十万个波一次算完
每个格子（波数 $\vec k$）一个随机复振幅：$h_0(\vec k)=\frac{\xi_r+i\xi_i}{\sqrt2}\sqrt{S(\vec k)\Delta k^2/2}$。时刻 $t$：

$$\hat h(\vec k,t)=h_0(\vec k)e^{-i\omega t}+\overline{h_0(-\vec k)}e^{+i\omega t}$$

这个组合保证 $\hat h(-\vec k)=\overline{\hat h(\vec k)}$，逆变换结果是实数。
**时间项的符号决定传播方向**：$h_0 e^{-i\omega t}e^{i\vec k\cdot\vec x}=e^{i(\vec k\cdot\vec x-\omega t)}$，波峰沿 $+\vec k$ 移动，与 Gerstner 的 $\cos(\vec k\cdot\vec x-\omega t)$ 相同。
Tessendorf 原文写的是 $e^{+i\omega t}$（波逆着 $\vec k$ 跑），第一版照抄，结果 FFT 的浪逆风走、与 Gerstner 方向相反 —— 单元测试「FFT 约定与 Gerstner 一致」用单个波逐点比较两者，GPU 自测再确认 shader 与 CPU 参考一致。
空间求导就是乘 $i\vec k$：

| 场 | 频谱 |
|---|---|
| 高度 $y$ | $\hat h$ |
| 水平位移 $\vec D$ | $i\frac{\vec k}{k}\hat h$（乘尖锐度 λ） |
| 斜率 $\partial y/\partial x$ | $i k_x \hat h$ |
| $\partial D_x/\partial x$ | $-\frac{k_x^2}{k}\hat h$ |

两个实数场打包成一个复数场 $A+iB$，一次逆 FFT 同时得到两者（实部、虚部）—— 8 个场只需 4 个复数通道、2 张贴图。
**打包的前提是每个场都是实数**，也就是每个场的频谱都满足共轭对称。网格下标 0 的那一行/列（Nyquist，波数 $-\frac N2\Delta k$）没有对称的 $-\vec k$ 格子 —— $-\vec k$ 折回到同一行/列自己身上。高度场在那里仍是实数，但乘上 $k_x$ 的导数场（例如 $D_{xz}$）变成纯虚数，打包后正好串进高度的实部。最小级联的波数范围一直延伸到 Nyquist，GPU 自测在那里测出约 80% 的高度误差（画面上是极细的棋盘噪点，肉眼几乎看不出）。修复：Nyquist 行/列的 $h_0$ 置零（这些波长只有两个格子，本来也表示不了方向）。
**每个格子的 $\omega$ 由 CPU 算好上传**（`cascadeFrequencies`），GPU 演化和 CPU 参考用同一组数：否则 float 舍入可能让个别频率落到不同的量化格上（见下文「时间」），相位差能到整整一圈。
**为什么三个级联**：一张 256² 网格只能覆盖约两个数量级的波长。三个级联（250 m / 37 m / 5.3 m）各负责一段波数，分界取在下一级联的第 6 个频率格（$2\pi/L\times6$），互不重叠（有单元测试验证总能量 ≈ $m_0$）。尺寸互不整除，看不出重复图案。
**逆 FFT 实现**：一个线程组处理一整行，256 个线程，8 级蝶形都在 groupshared 内存里完成（按位反转顺序载入，输出自然顺序）。先所有行、再所有列。频谱下标偏移了 N/2，结果要乘 $(-1)^{x+z}$。

### 泡沫：水面被挤到「折叠」
水平位移把水面点往浪峰挤。用位移映射的雅可比行列式衡量挤压：

$$J=(1+\lambda D_{xx})(1+\lambda D_{zz})-(\lambda D_{xz})^2$$

$J=1$ 平静，越小挤得越厉害，$J<0$ 水面自相交（浪头破碎）。新泡沫 $=\mathrm{saturate}((J_\text{阈值}-J)\cdot\text{强度})$，旧泡沫 $\times e^{-\Delta t/\tau}$，取较大者。
贴图坐标是**未位移的拉格朗日坐标**，泡沫自然跟着水面点漂移，不需要平流计算。需要读上一帧的结果 → Render Graph 新增**持久贴图**，泡沫历史（R32F）A/B 交替。
两个容易踩的坑：
- **历史和输出分开**。第一版把泡沫放在位移贴图的 w 通道里、整张位移贴图做持久 A/B —— 组装被跳过时，海面读到的是两帧前残留的旧位移（A、B 来回闪），而不是平静水面。现在位移/导数是普通瞬态贴图（只代表本帧），持久的只有泡沫历史。
- **第一帧没有历史**。这时绑定的是 1×1 的默认贴图，shader 用整数坐标 `Load` 去读 256×256×3 的位置是越界的（设备没开 `robustImageAccess`，结果未定义，不能指望读到 0）。现在由 CPU 用 `ctx.hasContent()` 判断、通过 push constant 告诉 shader「没有历史」，shader 根本不去读。
着色时用细节贴图打碎：覆盖率 $c$ 决定阈值，$\mathrm{smoothstep}(1-c,\,1.25-c,\,\text{detail})$ —— 覆盖率低时只剩最亮的气泡边。
岸边泡沫：沿视线的水厚度 × $|V_y|$ 近似竖直水深，小于宽度就起泡，再用正弦做「一波一波往岸上推」。

### Gerstner 参考实现
从同一频谱按对数频率分段取 32 个代表波，振幅 $a=\sqrt{2S(\omega)\Delta\omega}$，方向按 $D(\theta)$ 拒绝采样，陡度 $Q$ 保证 $\sum Qka<1$（不翻卷）。
约定与 FFT 一致：$y=a\cos\theta$，水平 $=-Qa\,\hat d\sin\theta$（水面点向浪峰聚拢）。法线与雅可比都有解析式。
CPU 端 `gerstnerHeightAt` 通过不动点迭代反解「哪个点被移到了这里」。

**由 $\omega$ 求 $k$**（`waveNumber`）：$f(k)=gk\tanh(kh)-\omega^2$ 单调递增，解唯一。第一版用不动点迭代 $k\leftarrow\omega^2/(g\tanh(kh))$：浅水时 $\tanh(kh)\approx kh$，迭代变成 $k\leftarrow\omega^2/(ghk)$，在两个值之间来回跳（2 m 水深、$\omega=0.5$ 时得到 0.0495，正确值 0.1139，波长和波速都错一倍多）。
现在用**带区间保护的牛顿法**：下界 $\max(\omega^2/g,\ \omega/\sqrt{gh})$（分别来自 $\tanh\le1$ 和 $\tanh x\le x$），上界加倍直到 $f\ge0$；牛顿步跳出区间就改二分，按相对残差 $10^{-10}$ 判断收敛。

### 时间：模拟时间与循环周期
- **海浪走模拟时间**（`RenderView::simTime`），不是墙钟：编辑器暂停、单步、慢放时海浪跟着停、跟着慢；并且插值到渲染时刻（上一步 + alpha × 步长），与实体的渲染插值是同一时刻。泡沫的衰减也用模拟时间的帧间隔，暂停时泡沫不消散。
- **循环周期 $T=1000$ s**：GPU 里时间是 float，运行几小时后 $t$ 只剩毫秒级精度，$\omega t$ 的误差让小波开始抖动。把所有 $\omega$ 量化到 $2\pi/T$ 的整数倍后，海面每 $T$ 秒精确重复一次，只需要传 $t \bmod T$（CPU 用 double 取模）。频率误差 $\le\pi/T\approx0.003$ rad/s，对最慢的波也不到 1%。岸边涌浪的相位同理在 CPU 用 double 取模后再传。

### CPU 高度查询的约定（M6 之前要定）
`OceanRenderer::heightAt(x, z, simTime)`：
- **Gerstner 模式**：与画面是同一组波，逐点一致（误差只来自反解水平位移的迭代）。
- **FFT 模式**：仍然返回 Gerstner 的结果 —— 统计上相同（波高、波长、方向），但**逐点不是同一片海面**。浮力直接用它，物体会按另一片海起伏，和看到的浪对不上。
M6 浮力之前要换成和 FFT 画面逐点一致的查询，几种做法见「扩展点」。

### GPU 结果校验（`sandbox --selftest ocean`）
单元测试只能测 CPU；GPU 上的 演化 → FFT → 组装 是否算对，以前只能「看起来对」。现在 CPU 端有一个**直接求和的参考实现**（`evaluateCascade`，每个点对 N² 个波求和，和 shader 一行对一行），自测脚本：
1. 回读 GPU 的位移/导数贴图（`OceanReadback` pass，拷到 CPU 可读的缓冲），每个级联随机抽 48 个点逐点比较，误差除以该分量的均方根，阈值 2%（正常约 0.2–0.5%，来自 half 精度）。
2. 首帧检查「没有泡沫历史」分支：泡沫必须正好等于新泡沫。
3. 逐个关 pass，检查下游状态（跳过 / 换默认贴图）和输出；重新打开后结果再次正确。
4. 暂停 7 帧，位移必须完全不变；连续拖动风速 120 帧，记录帧时间 P95/P99 与频谱重建次数。

它第一次运行就抓到了上面的 Nyquist 串扰。

### 水面着色
- **反射**：$F=0.02+0.98(1-N\cdot V)^5$（水的 $F_0$ 由折射率 1.33 算出）。朝下的反射线实际打到别的浪上：镜像到上半球取天空，并按向下的程度过渡到水体颜色。
- **太阳高光**：GGX，乘阴影（岛屿能把影子投到海上）；远处小级联淡出后，粗糙度随距离补回。
- **折射与吸收**：先把场景颜色/深度拷一份（同一 pass 不能既写又采样），沿法线扰动 UV；按 RGB 分别 Beer–Lambert：$T=e^{-\sigma\cdot d}$，被吸收的部分由水体散射颜色补上。红光吸收最强 → 深水蓝绿、浅水透出沙床。
- **浪尖透光**：逆光看浪头时 $(V\cdot -L)$ 大、浪尖高处（相对 $H_s$）带出青绿色。

### 网格与 LOD
以相机为中心的极坐标网格，环半径几何级数增长（0.5 m → 6 km），一张网格铺到地平线。
抗混叠：顶点间距超过级联尺寸 1/8 时该级联不参与几何位移（采样不足会抖）；像素覆盖超过级联尺寸 1/64 时不参与法线。
**绕序的坑**：极坐标的「径向 × 切向」指向 −Y，第一版三角形全是背面 —— 从上面看到的是背面，法线被翻到水下，整片海只剩菲涅尔反射、泡沫发褐。现在按正面朝上排列。

## 容错
| 情况 | 结果 |
|---|---|
| 关掉 OceanSpectrum / OceanFFTRows / OceanFFTColumns / OceanAssemble | 后面的 compute pass 因「必需输入（storage 读）没有内容」被 Render Graph 跳过，失败一路传到海面；海面读到默认黑色数组 → 平静水面 |
| 关掉 OceanPrepare | 海面由标志位得知没有场景拷贝：按深水着色、没有岸边泡沫（以前默认白色 = 1 米，整片海「零厚度」） |
| 关掉 Forward / Sky | OceanPrepare 用采样（而不是 `Load`）读场景颜色/深度，1×1 默认贴图不会越界 |
| 后台生成频谱抛异常 | 记错误日志，继续用上一份频谱 |
| 关掉 Ocean | 没有海面，其余照常 |
| 级联尺寸顺序写反 | 配置检查时自动按从大到小排序并警告 |
| 泡沫贴图缺失 | 用白色代替（泡沫变成整块，仍可见） |
以上都在 validation 下用 `--disable-pass` 逐个演练过；关 pass 后的**输出是否正确**由 `--selftest ocean` 检查。

**拖动滑条**：频谱参数一变就在后台生成（每个级联一个任务），同一时间最多一个任务，生成期间的修改合并成下一次。主线程只付上传（约 2 ms）。Release 下连续拖动风速 120 帧：P50 2.4 ms、P95 4.4 ms、P99 5.3 ms，频谱重建 25 次（以前每次修改都在主线程生成 + 上传，约 10 ms）。

## 练习
1. 「海洋」面板里把风速从 5 拖到 20，看有效波高按约 $U^2$ 增长；风区改成 10 km，再看浪为什么起不来。
2. 切换 Gerstner / FFT，对比近处的细节和泡沫。把 Gerstner 波数改成 4，看「只有几个波」的海有多假。
3. 把尖锐度调到 1.5、起泡阈值调到 1.1，观察泡沫出现在浪峰前沿；再把消散时间调到 10 秒，看泡沫拖成长条。
4. 吸收 RGB 改成 (0.05, 0.05, 0.05)：水变清、海床清晰；改成 (0.5, 0.3, 0.05)：变成偏绿的沼泽水。解释为什么。
5. 打开线框，从高处看极坐标网格；把「环数」降到 32，看远处的浪如何变平（几何权重淡出）。
6. 进阶：在 `ocean_assemble.hlsl` 里把泡沫改成「累加」（`prev * decay + fresh * dt`）而不是取最大值，比较两者的视觉差异。
7. 把 `ocean_evolve.hlsl` 里的 `Conj(e)` 和 `e` 对调（回到 Tessendorf 原文的符号），运行 `sandbox --selftest ocean`，看校验如何报错；再切到 Gerstner 模式对比浪的走向。
8. 编辑器里暂停（工具栏「暂停」），观察海浪和泡沫一起停住；把时间缩放调到 ×0.25 看慢动作的浪。
